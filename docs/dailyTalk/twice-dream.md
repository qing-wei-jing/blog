# 二重梦境记录

昨晚做了一个非常真实的梦。

准确地说，那不是一个普通的梦，而是一个套着另一个梦的“二重梦境”。直到最后真正醒来，我才意识到，自己曾经在梦里以为已经回到了现实。

## 第一重梦境：回到高中

第一重梦境里的场景，好像是在高中。

梦里发生了两件比较清晰的事情。

第一件事是在上课的时候，我放在课桌里的手机突然响了。声音在教室里显得格外明显，随后手机就被没收了。

第二件事是一场考试。

我坐在教室里，试卷上是一些计算机编程题，一共十道。那些题看上去都很基础，按理说应该不难，但梦里的我偏偏一道也不会做。

奇怪的是，就在这个时候，我意识到自己正在做梦。

既然是梦，好像也就没有继续考试的必要了。于是我干脆没有答题，只是坐在那里，看着周围的人陆续交卷。后来，我也离开了教室。

## 第二重梦境：我以为自己已经醒了

第二重梦境比第一重模糊得多。

我只记得，那时的我知道前面高中教室里发生的一切都是梦。我保留着第一重梦境的记忆，也正因为如此，我理所当然地认为：刚才的梦已经结束了，现在应该是真正的现实。

这一次，场景好像是在大学，似乎仍然与考试有关。

因为我判断这里是现实，所以没有像第一重梦境里那样直接放弃，而是稍微做了一下题。可越往后，记忆就越模糊，梦里的现实感也开始变得不稳定。

渐渐地，我已经分不清自己究竟是在梦里，还是已经真的醒了。

到了最后，我好像隐约感知到了一些来自现实的东西,然后就醒了

## 醒来之后

醒来以后回想这段经历，最神奇的并不是梦见了校园和考试，而是我在第二重梦境里真的相信自己已经醒了。

第一重梦境中，我因为知道那是梦，所以可以不去理会考试和规则；第二重梦境中，我因为相信那是现实，便重新认真对待眼前的一切。梦境甚至利用了我“已经识破上一场梦”的记忆，让下一层显得更加可信。

那种体验很像从一个房间推门出去，以为终于来到了外面，后来才发现，所谓的外面其实只是另一个更大的房间。

好在最后，我还是醒了。

现在把它记录下来，是因为梦境的细节正在一点点消失。也许过一段时间，我会忘记那几道题、那间教室，甚至忘记自己是怎样醒来的，但我应该还会记得那种感觉：

**我曾经在梦里醒来，并且有那么一段时间，完全分不清梦境与现实。**
